# Multi-Domain Data Analytics Portal

A portfolio website showcasing data analytics dashboards across multiple business domains, built using AI-assisted development with Lovable.

🔗 **Live site:** https://miniprojectdashboard.lovable.app

## Purpose
To present my Power BI and Excel dashboards in one place and show how data analytics can be applied across industries.

## Dashboards Showcased
| Domain | Dashboard | Tool |
|---|---|---|
| Entertainment | Netflix Analytics Dashboard | Power BI |
| Elections | Election Campaign Report 2026 | Power BI |
| Elections | Election Survey Analysis | Excel |
| Customer Service | Call Analysis Report 2026 | Power BI |
| Retail | Superstore Sales Analysis | [Power BI / Excel] |
| Business | Lead Management Dashboard | Power BI |

## Features
- Project gallery with dashboard previews
- Analytics workflow and tools overview
- Dataset upload and analysis page
- Contact section

## Built With
Lovable (AI-assisted web development), Power BI, Microsoft Excel
